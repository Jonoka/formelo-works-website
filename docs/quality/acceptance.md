# 检查与验收状态

## 初始化包检查（可运行）

`python3 scripts/check_repository.py` 验证导入哈希、WebP 文件头及尺寸、10 路由 / 8 模板 / 9 生产可索引项、导航目标、空账号与概念开关、资产存在性、Markdown 本地文件链接和明显秘密文件 / 字符串。
该扫描仅基础防呆，不是全面安全审计；不验证外部网页、邮箱收发、页面渲染或生产 SEO。
`python3 -m unittest discover -s tests -p 'test_*.py' -v` 用伪造的 gh 响应和本地裸 Git 库验证建仓脚本控制流程，不连接 GitHub。
`bash -n scripts/publish-github.sh` 检查 Bash 语法。
CI 配置随初始化 PR 交付；实际运行状态以 GitHub Actions 为准，不用本地报告代替远端结果。

## DEV-01 工程底座与完整应用验收

工程检查命令为 `npm run verify` 和 `npm audit --audit-level=high`，实际执行环境、结果和限制见 [DEV-01 验证记录](../operations/dev-01-verification.md)。它只覆盖本地 mock 首页 / 404、内容模型骨架与工程安全边界；不能用于勾选完整十页、真实 CMS 或生产用例。

沿用 [PRD 第 16 章](../product/prd-v1.0.md) 的 T-01～T-45 及 [UI 第 16 章](../reference/ui-ux-kickoff-v1.0.md) 的 UI-V01～UI-V16。
已选画面方向明确，不意味着移动端、代码、生产素材或所有 UI-V 用例已通过。
原型与生产差异如下：

| 场景 | 概念预览允许 | 生产要求 |
|---|---|---|
| 品牌 | FORMELO WORKS 临时字标，明确提示 | 最终品牌与实际主体确认 |
| 图片 | 明确标记的 AI 服装概念图、工厂灰框 | 正式授权与事实一致，工厂证据真实；必要素材交齐 |
| 联系 | null，按钮不向假账号跳转，有待配置提示 | 真邮箱 / 号码，手机与桌面主动收发 |
| 索引 | 非生产 noindex 且访问受控；本轮没有部署 | 真实规范域名、9 项 sitemap、Privacy noindex |
| 业务文案 | 标注待审核、避免数字承诺 | 工厂审核能力 / MOQ / 打样等信息 |
| 分析 | off，不采集 | 可保持 off；开启须另行批准并测试 |

不得把原型通过标记为生产完成。原 PRD 的真实样品数量和工厂图最低要求如需变更，应另记录决定，而不是用概念图自动充数。
