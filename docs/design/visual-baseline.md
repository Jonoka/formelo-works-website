# 已选视觉实施基线

基于用户选定的 1024×1536 PNG。这个尺寸是参考图的像素尺寸，不是已验证的浏览器视口或 CSS 尺寸。
768×1152 WebP 查看版位于 [homepage-selected-v1.webp](../../assets/reference/homepage-selected-v1.webp)，文件哈希见资产台账。1024×1536 PNG 原图保留在原会话启动 ZIP；查看版经过缩小与有损压缩。这里是拆解与实施建议，不是已完成前端。

## 1. 应保留的视觉语言

大面积近白背景、炭黑高对比衬线标题、朴素无衬线正文、砖红色 WhatsApp 主按钮、描边 Email 次按钮、灰阶服装与混凝土纹理、细线分段、直角图片和深底联系页脚。
Logo 为字距较宽的文字标识。无需先做图形商标；品牌文字不能写死在图片里。
避免通用蓝白企业模板、黑金风、荧光渐变、大圆角卡片和重阴影。不存在对任何字体的准确识别结论。

## 3. 字体与变量

`tokens.json` 提供实施候选值，不是截图原始设计源数据。标题先用系统 Georgia / Times 类衬线作开发回退，正文使用系统无衬线；后续选择合法 web font 后记录来源、许可与版本，再比较实际字形 / 换行。
不提供或复制运行环境中的字体文件。
建议主标题桌面约 64–88 CSS px、手机 38–48px；正文 16–18px，关键采购条件不得变成极小浅字。
宽屏文字区约 1280px 上限（可在 1200–1360px 间随评审调整），不是原 PRD 1200px 的业务约束变更。手机 20px 边距，极窄 16px。

## 4. 响应式交接

桌面 Hero 约 48:52 图文分配；不固定整页高度，不机械复制图上的每一行断行。
小于 1024px 使用原生可访问折叠菜单；小于 768px Hero 按标题 → 简述 → CTA → 图片顺序。主要按钮至少 44×44，建议高 48px。
320 / 360 / 390 / 768 / 1024 / 1440px 和 200% 缩放测试；手机不是把整张桌面图缩小。
底部联系条可保留，但须预留高度 / safe area、菜单展开时隐藏，Privacy / 404 不显示。

## 5. 图像和真实性

目前仅有完整首页参考图；没有独立高清 Hero、类别图或工厂图。资产条目 `pending_generation` / `awaiting_factory` 不代表文件已经存在。
下一轮生成同一色温 / 质感的无品牌服装图，保留原始与网页优化版本。参考图不得裁成含文字的小图冒充干净图片，不将原图作为页面背景还原。
概念模式保留全局 preview / provisional / unconfirmed 说明；没有接入 AI 图时不声称页面已显示 AI 图。每个图片槽位持续显示准确的 pending 或 AI-generated concept 图注；真实生产图片与证书仍等工厂提供。

## 6. 可用性与视觉验证

图片上文字、按钮各种状态和暗底分别测对比度；一般正文 4.5:1、大字 3:1 是已有 PRD 的质量约束。
页面文字、链接、图标和装饰由 HTML / CSS / 可访问 SVG 实现；不使用整页图片 / canvas 截图替代正文。
拒绝滚动劫持、开屏加载、鼠标特效、重视频。内容默认可见，减少动态效果时关闭非必要动画。
实现后对照原图提交 1440px 桌面与 390px 手机截图，列出有意微调，不能仅凭“看起来高级”验收。
