# 首页视觉衔接记录

## 原方向和核对方式

沿用 [已选基线](visual-baseline.md) 与 [原参考图](../../assets/reference/homepage-selected-v1.webp)。本轮读取原 WebP，并实际渲染查看其等比缩小预览（240×360）；不是只根据文件名推测内容。该预览足以核对大构图，不作为原像素字体/细节的精确测量证据。
保留暖白、炭黑衬线大标题、砖红主按钮、细分隔线、不对称网格和深色页脚。不重新探索其他风格，不导入字体文件。

## 本轮实施微调

首页主段落改为面向独立品牌的 fabric / fit / finish 与 brief 文案。服务尚未确认的事实单独紧邻说明；能力栏依旧标为 proposed，两个品类依旧 demonstration only。未添加 MOQ、交期、价格或生产能力承诺。
新增公共 `SectionHeading`，集中区块标题/副说明结构，并保留隐藏换行符时词间空格；桌面/手机/页脚导航引用同一组实际首页锚点。Hero 的原语义断行仍以共享 title 为准，不用固定样式覆盖更新后的标题。
能力、品类介绍、流程正文使用至少 16px；注释不再承担主要客户正文。事实状态使用细竖线分层，颜色和字体保持现有 tokens，不另建逐页样式系统。
图片组件增加明确的加载失败图注；外置增强脚本、无 JS 原生菜单/FAQ、reduced-motion、安全区和空联系方式保持。
