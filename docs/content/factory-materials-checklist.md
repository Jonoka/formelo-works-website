# 工厂待补资料与确认清单

本清单是后续资料交付任务，不是已收到的资料或能力证明。当前 Manufacturing / Factory / Contact 文案仅供概念审阅；所有真实业务字段和审核日期仍未确认。网站团队整理英文和页面，工厂负责事实、接待与履约，不改变工厂自身官网身份。

| 资料 | 需要确认的内容 | 当前处理 |
|---|---|---|
| 品牌与主体 | 工厂英文名称、展示品牌及其关系、允许公开的地区/地址、文字介绍 | 临时品牌；主体与地址为 null，不填厂龄/规模等数字 |
| 两个真实品类 | 实际优势、能做与不能做的范围、可公开的材料/工艺/版型说明 | T-shirts / Hoodies 仍是演示品类 |
| 定制方式 | 是否有可改的基础款、加标、改版、从零开发；各自限制和所需资料 | 只写客户可提的问题，不当作服务清单 |
| MOQ 条件 | 按款/色的计量、混码条件、面辅料和工艺影响、品类差异 | 无统一数量、示例 MOQ、价格或交期 |
| 打样与确认 | 是否承接、需什么资料、费用原则、时间条件、反馈/修改范围及确认方式 | 未承诺免费打样或修改轮数 |
| 制造安排 | 各阶段的负责人、实际地点、厂内与外协范围、信息确认方式 | 不默认所有工序都在厂内完成 |
| 质量检查 | 实际阶段、检查内容/方法、约定标准与容差、问题沟通和处理责任 | 只呈现待讨论框架，无零缺陷或通过率承诺 |
| 真实工厂摄影 | 至少三张可公开的真实工厂图及准确工序说明；授权范围、替换对象 | FACTORY-001 仍 awaiting_factory；不生成车间、工人或证书代替证据 |
| 真实样品 | 每品类至少三组获准公开样品及稳定公开编号、照片与相关说明 | 不把三张 AI 概念图变成虚假样品目录 |
| 联系渠道 | 一个真实接待邮箱、WhatsApp 国际号码、接待人/部门、工作时段与时区、可公开地址 | 全部 null/disabled；无示例地址、假号码或在线状态 |
| 可选证书/案例 | 真实主体、范围、有效期、图片和客户使用许可 | 无资料时隐藏；没有假 Logo 墙或空链接 |

## 审核与素材边界

每条可公开事实记录其对应页面、英文表述、确认人、真实确认日期和状态。不要以部署日期代替工厂审核日期，不给概念数据塞入 Sanity asset._ref 或 fake seed。可公开图片须核对版权、描述准确性和必要的隐私清理；客户订单、内部报价及授权原件留在约定的内部渠道，不通过本站上传。

客户开始沟通不以 Tech Pack、企业邮箱或注册品牌为前提；这不等于承诺工厂提供所有设计开发服务。资料准备说明只帮助提问，具体项目可行性由工厂确认。

## 授权联调前置条件

账号与接待人提供并获准测试后，再安排邮箱/WhatsApp 的真实打开、主动发送、工厂收件与回复，以及复制成功/失败降级。只打开客户端不算收到询盘；本轮没有发送任何消息。真机、Safari/Firefox/Edge、CMS 接入、Privacy 实际主体/工具文本和生产发布分别安排，不因三页概念完成而关闭。
