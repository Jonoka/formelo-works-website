## 素材与品牌替换

临时品牌只维护 `site.example.json` 和后续 `siteSettings` 的单一值，禁止烧录到服装图。
换真实品牌时检查文案、Logo、title / OG、结构化数据、页脚、联系模板与隐私主体。
更换真实图片时保留适当构图与裁切焦点，更新 alt / caption / asset manifest / 审核记录；不靠把文件名换掉假装审核完成。
